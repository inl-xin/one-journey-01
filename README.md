Entry for the make.fun bounty `u-gudril-cool-one-sentence-one-journey-410686ca`
("One Sentence, One Journey"), by @inl-xin.

A complete journey in exactly one sentence: she sells the house,
books a one-way ticket under her mother's name by mistake, and by the
border — where a guard mispronounces it twice — she has stopped
correcting him, travelling lighter than she ever had.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.txt`, byte-identical on repeat runs. Python 3,
standard library only; no network.
